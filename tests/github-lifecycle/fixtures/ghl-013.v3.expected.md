Every PR body, ready-for-joel packet, and report to Joel leads with a budgeted plain-English block so adjudication happens at the altitude where the owner's judgment is strongest. Doctrine amendment only; mandated by Joel 2026-07-27 (agent-scripts issue #18).

## Dependencies

## Acceptance criteria

- Amend the contributor operating protocol so the packet contract requires an "In plain terms" lead block: three to five jargon-free sentences covering what changes in the world, what could go wrong, how undoable the change is, and the one thing to read if only one.
- Amend the contribution review architecture with the plain-terms layer, its rationale, and its named failure modes: the plain layer must never replace the technical record, must inform rather than persuade, and must never omit what could go wrong.
- State the proportionality rule: one-way-door decisions get the full decision-analysis.v1 treatment; small two-way doors get the minimum budget.
- Record changelog entries in each amended document.
- Keep the amendment documentation-only; no schema, validator, or renderer changes.
